\section{Conclusion}
\label{sec:conclusion}

We presented a unified framework for cost- and latency-aware LLM routing across heterogeneous providers with pay-per-token APIs, quota-limited subscriptions, and concurrency-limited subscriptions. We derived offline optimal algorithms---greedy-by-value for quota constraints and time-indexed ILP for concurrency constraints---establishing theoretical lower bounds. For online routing, our Learning-Augmented Primal-Dual algorithm achieves a 1.18$\times$ competitive ratio by combining shadow pricing with quantile regression for conservative value estimation. For latency optimization, we introduced LP-based provider mixing and survival-analysis-driven smart hedging. In 24-hour experiments on real API providers, our approach reduces SLO violations by 31$\times$ and P99 latency by 5.5$\times$ compared to OpenRouter's default routing, while achieving 37\% cost savings. Our framework applies broadly from third-party API routing to enterprise GPU cluster scheduling.
