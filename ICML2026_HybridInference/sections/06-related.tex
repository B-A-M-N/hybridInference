\section{Related Work}
\label{sec:related}

\paragraph{Online Algorithms and Competitive Analysis.}
Our work builds on the rich theory of online algorithms, particularly the \textit{online knapsack problem} where items arrive sequentially and irrevocable accept/reject decisions must be made. The primal-dual framework provides a principled approach to designing online algorithms with provable competitive ratios. The \textit{ski-rental problem}---the canonical rent-vs-buy decision under uncertainty---is closely related to our subscription-vs-API routing decision. However, our setting is more complex: requests are heterogeneous (varying costs), and we face multiple interacting constraints (quota and concurrency). We extend these classical frameworks to handle the specific structure of hybrid LLM routing.

\paragraph{Learning-Augmented Algorithms.}
The emerging field of \textit{algorithms with predictions} studies how machine learning can improve the performance of online algorithms. The key insight is that predictions, even imperfect ones, can help algorithms beat worst-case competitive ratios while maintaining robustness guarantees when predictions fail. Our LA-PD algorithm follows this paradigm: we use quantile regression to predict output token counts, enabling risk-aware routing decisions. Unlike point predictions, quantile estimates provide calibrated uncertainty, allowing us to make conservative decisions (using the 10th percentile) when the stakes are high.

\paragraph{LLM Serving Systems.}
Recent systems work has focused on optimizing the throughput and latency of individual LLM serving instances. vLLM introduces PagedAttention for efficient KV-cache management, dramatically improving throughput. SGLang optimizes the execution of structured LLM programs with RadixAttention for prefix caching. Orca pioneered iteration-level scheduling for continuous batching. These systems optimize \textit{within} a single serving instance; our work is complementary, optimizing the \textit{routing layer} that dispatches requests across multiple heterogeneous instances with different pricing models.

\paragraph{GPU Cluster Scheduling.}
Scheduling deep learning workloads on GPU clusters has received significant attention. Gandiva enables time-slicing and migration for DL jobs. Tiresias uses attained service for job scheduling without duration estimates. Themis ensures fairness in ML cluster scheduling. These systems focus on training workloads with long-running jobs; our setting differs in that inference requests are short-lived, latency-sensitive, and arrive continuously. The gutter pool concept we model is related to the broader challenge of maintaining high availability in GPU clusters, where spare capacity must be provisioned for failover.

\paragraph{Cloud Resource Management.}
The hybrid pricing structure we study mirrors patterns in cloud computing. AWS, GCP, and Azure offer Reserved Instances (discounted, committed capacity), On-Demand Instances (elastic, expensive), and Spot Instances (cheap, preemptible). Optimizing across these pricing tiers is well-studied in cloud economics. Our quota constraint ($S_Q$) is analogous to reserved capacity, while the pay-per-token API ($S_A$) resembles on-demand pricing. The key difference in LLM inference is that request ``value'' (output tokens) is unknown at routing time, introducing a prediction challenge absent in traditional cloud scheduling.

\paragraph{Output Length Prediction for LLMs.}
Predicting the output length of LLM requests is crucial for both scheduling and cost estimation. Recent work has explored using input features (prompt length, task type, conversation history) to predict output tokens. DistServe separates prefill and decode phases based on predicted output lengths. Our histogram-based predictor follows this line of work but focuses on quantile estimation for risk-aware decisions rather than point predictions for scheduling.
