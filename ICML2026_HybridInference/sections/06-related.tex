\section{Related Work}
\label{sec:related}

\paragraph{Online Algorithms.}
Our work builds on the \textit{online knapsack problem} and \textit{ski-rental problem}---the canonical rent-vs-buy decision under uncertainty. The primal-dual framework provides provable competitive ratios. Our setting extends these frameworks with heterogeneous requests and multiple interacting constraints (quota and concurrency).

\paragraph{Learning-Augmented Algorithms.}
The emerging field of \textit{algorithms with predictions} studies how ML can improve online algorithms beyond worst-case competitive ratios. Our LA-PD algorithm follows this paradigm: we use quantile regression to predict output token counts, enabling risk-aware routing. Unlike point predictions used in prior work on output length prediction for LLM scheduling, quantile estimates provide calibrated uncertainty for conservative decisions.

\paragraph{LLM Serving Systems.}
Recent systems work has focused on optimizing the throughput and latency of individual LLM serving instances. vLLM introduces PagedAttention for efficient KV-cache management, dramatically improving throughput. SGLang optimizes the execution of structured LLM programs with RadixAttention for prefix caching. Orca pioneered iteration-level scheduling for continuous batching. These systems optimize \textit{within} a single serving instance; our work is complementary, optimizing the \textit{routing layer} that dispatches requests across multiple heterogeneous instances with different pricing models.

\paragraph{Cloud Resource Management.}
The hybrid pricing we study mirrors cloud computing patterns: reserved instances (discounted, committed) vs on-demand (elastic, expensive). Our $S_Q$ is analogous to reserved capacity, $S_A$ to on-demand. The key difference is that request ``value'' (output tokens) is unknown at routing time.
